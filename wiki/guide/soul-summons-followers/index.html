Soul Summons (Followers)

The Beacon of Hope drops from your first Normal Baal kill. Soul Shards drop from the Spirits and Baal (75% chance, more while terrorized) and the Three (about 2.5 per kill). They stack in their own slot on the stash's Materials tab (ctrl+click files them there).

Beacon + Soul Shards in the cube = adds 1-3 Soul Shards per shard to the Beacon.

Beacon alone (200+ Soul Shards) = a Class Token. Cube a token alone to change its class.

Beacon + 1 Class Token = unlock your first Soul. It appears as an oskill on the Beacon.

Beacon + N tokens of that class = upgrade that Soul to tier N (tier 10 takes 10 tokens).

One token of each class = an Expansion Token. Beacon + Class Token + Expansion Token = unlock another Soul.
