Patch notes

Every release, newest first. The launcher installs updates for you.

2026-10-20

1.1.44: The Spirit of Diablo stops lagging the game

The Spirit of Diablo no longer lags the game. Like the Chaos Spire map bosses in 1.1.43, his Fire Wall piled up into hundreds of flames during the fight with the Three. He no longer casts it - his lightning, cold, fire breath, charge and Bone Prison are unchanged.

The same goes for the other copies of Diablo (Uber Diablo and the Diablo clone). The real Diablo in the Chaos Sanctuary keeps his Fire Wall: he casts it at the normal pace and never piled it up.

2026-10-20

1.1.43: Running Hoardlings, smoother map bosses

Hoardlings run. They used to stand around after appearing - now they bolt from the moment they spawn and keep running, blinking away when you corner them. Same loot, same 40 seconds to catch one once you've hit it.

Chaos Spire map bosses no longer lag the game. Their Fire Wall piled up into hundreds of flames near the throne. They no longer cast it - lightning, cold, the flame pentagram and the charge are unchanged.

Smaller updates from now on. The version number moved out of the big Heyday.mpq file, so updates that don't change game data no longer re-download all 221 MB. This update still downloads it once; the next ones that only fix code won't.

2026-10-19

1.1.42: Town portal crash fix

Crash fix: taking a town portal out of a map with the map open. Leaving the Tier 2 Chaos Spire map (and Hells Torment 25) through a town portal while the automap was up crashed the game. Those areas shared their automap layer with a town's, which the game doesn't handle. They - and three Frost Pool areas with the same problem - now have their own layers. Thanks to everyone who reported it.

2026-10-19

1.1.41: Crash fix

Crash fix: leaving a game after a map. The crash reports from 1.1.40 found it within hours: after you left a game, one of Heyday's plugins could still check on the game you had just left, a few seconds after the game had freed it - and crash, often right as you joined your next game. Heyday's plugins now leave the game alone as soon as you're out of it. Thanks to everyone whose launcher sent a report.

2026-10-19

1.1.40: Crash reports

Crash reports. When a Heyday game crashes or logs an error, the launcher now sends a report to Heyday by itself, so problems get fixed without anyone having to post logs in Discord - especially on Battle.net, where your game version can differ from the one Heyday is tested on. A report holds the version numbers, the game's crash report text and Heyday's own error lines and plugin logs. Your Windows user name, PC name and folder paths are taken out first, and nothing is sent about games that went fine. Don't want it? Untick Send crash reports in the launcher. (Launcher 1.2.14 - it updates itself.)

2026-10-19

1.1.39: Features back on other game versions

Battle.net players: features are back. 1.1.38 switched map affixes, Hoardlings, Loot Bags opening, Drop Limit and the multiplayer boss-life fix off on any game version other than Steam's, to stop the crashes. Now Heyday looks for the game code those features use on whatever version you run, instead of expecting it at one fixed place: where it finds everything a feature needs, the feature turns on; where it doesn't, that feature stays off (no crash). Map affixes, Loot Bags, Drop Limit and the boss-life fix should now work on Battle.net. Hoardlings and the monster-spawning map affixes (Teeming, Swarming, Legion, Horde) stay off there until a Battle.net player's plugin log confirms them - if you play on Battle.net, please post your Heyday plugin logs (mods\Heyday\d2rloader\logs) on Discord.

2026-10-19

1.1.38: Crash fix

Crash fix for some players (Battle.net). Several of Heyday's features use the game's own code directly, and they were built for one game version. On a different one - the Battle.net version can be newer than Steam's - they could crash the game, often after a town portal in a map. Now those features switch themselves off on any game version they weren't made for instead: no more crashes, but on that version map affixes, Hoardlings, Loot Bags opening and the multiplayer boss-life fix don't work until Heyday supports it. The plugin logs (mods\Heyday\d2rloader\logs) say when that happens.

2026-10-19

1.1.36: A Hoardling in every map

Every map holds a Hoardling now - and they turn up partway through the map instead of on the first kills: maps hold over 2,000 monsters, so a Hoardling comes somewhere in the first half of the clear. The of the Hoard / of Plunder map affixes bring two or three, spread out one after another (a Teeming or Swarming map spreads them further). Hell's Torment and the rips are unchanged.

2026-10-19

1.1.35: More map affixes, every player's maps, Chinese fix

New map affixes. Teeming / Swarming: +50% / +100% monsters - plain monsters bring a twin - and more experience. Legion / Horde: +50% / +100% champion and unique packs, each with its minions, and more magic find. Suffixes of the Hoard / of Plunder: +100% / +200% chance of a Hoardling (of Plunder: every map holds one). Rare maps can stack them with the rest.

Every player's maps count. In a multiplayer game, a map opened by any player now brings its affixes - before, only the host's maps did.

Simplified Chinese: some menu labels showed asterisks after 1.1.32's font change - fixed (thanks, Solaris).

2026-10-18

1.1.34: Map affixes, rare maps, Torment teleport

Map affixes. Every new map now drops magic or rare, and its affixes change the run you open it for - the maze and the boss chamber, only while you're inside. Prefixes make the map harder and pay for it: Fortified / Bastion (monsters +40/80% life, more experience), Brutal / Savage (+30/60% monster damage, more experience), Frenzied / Rabid (faster monsters, more magic find) and Warded / Impervious (monsters resist more, more magic find). Suffixes are pure reward: magic find (of Fortune / of Providence), gold (of Avarice / of Midas) and experience (of Insight / of Enlightenment). The stronger affix of each pair rolls only on maps from Tier 2 and 3 maps, deep Hell's Torment and the hardest rip. A rare map rolls up to three prefixes and three suffixes, so the dangers stack - and so do the rewards. Maps made in the cube (the orbs and the 3-to-1 recipe) roll new affixes, so an orb is also a reroll. Maps you already have stay as they are.

Map bosses no longer drop a guaranteed map. Maps come from clearing the map: the same tier from its monsters, the next tier from its champions and uniques, the 3-to-1 recipe or an Orb of Ascension. Bosses still drop a guaranteed map orb.

Teleport in Hell's Torment. Teleport now works in all 50 levels and the Icechambers the way it does in Duriel's Lair: anywhere you can see, never over or through a wall.

Loot Bags now open with the Transmute button of the stash's cube tab, not only the Horadric Cube's.

2026-10-18

1.1.33: Multiplayer boss fix, tougher Hoardlings

Bosses no longer break in big games. A monster's life tops out at about 8.4 million, and with enough players in the game Heyday's toughest bosses - Baal, the Spirit of Diablo, the Tier 2 and 3 map bosses - went past it and wrapped around to a broken value. Now they get the maximum the game allows, and they take proportionally less damage so they fight as tough as they were meant to for your player count. Single-player and small games are unchanged.

Hoardlings are twice as tough. They were dying before the chase could start. They still drop loot every tenth of their life and escape 40 seconds after your first hit.

2026-10-18

1.1.32: Hoardlings

Hoardlings: glowing loot thieves. A map has a one-in-three chance to hold one, and they turn up now and then in Hell's Torment and the rips - a banner and a coin jingle tell you when one is near. They don't fight back: they run from you, blink away when cornered, and are very tough. Every tenth of its life you take, a Hoardling drops some of its loot; kill it for the big haul. Be quick - 40 seconds after your first hit it escapes with whatever is left.

Seven kinds: Gilded (gold), Gem (perfect gems and Gem Clusters), Rune, Bag (Loot Bags), Cartographer (maps and map orbs), Soul (Soul Shards) and the rare Jewel Hoardling (magic and rare jewels, and a chance at a unique jewel when you kill it). Their names show in gold, and MapSense marks them on your map.

MapSense names bosses correctly. Map bosses and other added superuniques no longer show another boss's name on the map.

Simplified Chinese now uses the Traditional Chinese font family for the main UI font, so both Chinese languages match - thanks to Solaris for the suggestion.

The download is a little smaller: Heyday no longer ships unchanged copies of the game's own files.

2026-10-17

1.1.31: Diablo unfrozen, Materials slots, new Loot Bag look

Diablo's copies no longer freeze. The Spirit of Diablo, the Uber/Clone Diablo and the map boss Seal Warden Kaeos could lock up for good after casting Fire Wall, Prime Firewall, Bone Prison or Diablogeddon - stuck on the last frame of that spell's animation. They now cast those spells with Diablo's fire-breath and lightning animations instead: same spells, same strength, and they keep moving, charging and attacking. The real Diablo in the Chaos Sanctuary is unchanged.

Materials tab: Soul Shard and Loot Bag slots. Both now have their own slot on the stash's Materials tab (next to the Token of Absolution), with the faded picture while empty. Ctrl+click files them in and they stack with a count; click the slot to take one out.

Loot Bags have a new look: a crimson sack with a gold question mark, so they don't get mistaken for anything else.

2026-10-17

1.1.30: league fix for Loot Bags

Launcher 1.2.13 fixes "unapproved plugins: d2rl-heyday-lootbag.dll". 1.1.29's Loot Bags plugin is part of Heyday, but the launcher didn't know it yet and refused league play. Restart the launcher - it updates itself - and league play works again. From now on the launcher approves every plugin the installed Heyday release ships (checked by file hash), so new Heyday plugins can't trip this again.

2026-10-17

1.1.29: Loot Bags, richer maps

New: Loot Bags. They drop in the maps (regular monsters 1 in 150, champions 1 in 15, uniques 1 in 3), Hell's Torment (1 in 500, champions and uniques 1 in 50) and the rips (1 in 700, 1 in 70). Put a bag in the Horadric Cube by itself and press Transmute: it opens and its loot falls at your feet. Each bag rolls three times - nothing, junk gear, potions (Experience, Magic Find, Sunder), magic/rare/unique jewels, Soul Shards, Gem Clusters, keys, a Standard of Heroes, orbs, runes, a unique ring or amulet, or an Ancient Statue. The better the rarer: per bag about 1 in 40 for a unique ring or amulet, 1 in 70 for a unique jewel, 1 in 44 for a high rune.

Maps are busier: 14-20 unique and champion packs per map (was 6-10) and more monsters.

Map unique monsters drop much more: 10 item picks each (about twice what they dropped).

Map bosses roll the Three's loot at half the chance - half the item rolls, unique jewel, charm, Gem Cluster, Standard, Power Orb and Soul Shards - on top of their guaranteed next-tier map and map orb.

2026-10-17

1.1.28: map bosses stronger

The map bosses are tougher, and now measured in the game itself. 1.1.27's numbers came from a formula that turned out to be badly off - in game, The Abbess and Seal Warden Kaeos had only a fifth to two fifths of the Spirit of Diablo's life. Now, against the Spirit of Diablo's real life:

- Tier 1: half its life

- Tier 2: three quarters

- Tier 3: the same as the Spirit of Diablo

Their damage and loot are unchanged.

2026-10-17

1.1.27: map bosses rebalanced

The map bosses were far tougher than intended - up to ten times the life of the Three. They now scale by tier, measured against the Three's Spirit of Diablo:

- Tier 1: the same life and damage as the Spirit of Diablo.

- Tier 2: 1.5x the life, 1.25x the damage.

- Tier 3: 2.5x the life, 1.5x the damage.

Their loot is unchanged: item rolls by tier, the boss bonus roll, a guaranteed map of the next tier and a guaranteed map orb.

2026-10-16

1.1.26: map bosses

Every map has a boss. Find the stairs down in the map's maze to reach its boss chamber:

- Ruined Cathedral: The Abbess, in the Cathedral Sanctum.

- Chaos Spire: Seal Warden Kaeos, on the Spire Throne.

Each kill drops 4 / 5 / 6 item rolls by tier at boosted unique and set odds, the boss bonus roll, a guaranteed map of the next tier (Tier 3 bosses drop Tier 3) and a guaranteed map orb. The chambers are terrorized too.

Map champions and uniques now roll the terror-zone elite tables, like Hell's Torment's, on top of their map drops.

Find Item fixed. It was finding maps, map orbs, runes and elite gear far too often - it skipped the part of the loot tables that makes those rare. It now finds them at the same odds as a kill. Those extra drops (maps, orbs, Torment's depth rolls, keys...) also no longer increase with the number of players in the game.

Ctrl+click a map from any stash tab to send it to the Maps tab (Shift+click still works), and the Maps tab flashes when a map or map orb goes into it, like the stash's other tabs.

2026-10-16

1.1.25: the guide matches the game

Hell's Torment champions and uniques now get better with depth too. Until now only regular monsters got the depth bonus. Champions and uniques now also roll an extra rune and a piece of elite gear with raised unique odds, and both improve at monster level 114, 118, 122 and 125. That's on top of everything they dropped before.

The Heyday Guide, the wiki and the loot reference now read every number straight from the game data, so they can't drift from the game again. Fixed along the way:

- The Three always roll their terror-zone table, because their chamber is always terrorized: 10 item rolls, a 1 in 4 unique jewel (it was never guaranteed), a charm with boosted unique odds, a Gem Cluster, a 1 in 4 Standard of Heroes, a Power Orb and about 2.5 Soul Shards. Their drops don't change - the guide was describing a table they never used.

- Map orbs don't drop from the Three (1.1.24's notes said they did). They drop in maps, Hell's Torment and Hell terror zones.

- Hell's Torment is shown as always terrorized, with one drop table. The guide no longer mentions the charm/jewel bonus roll that was removed in 1.1.18, and the depth bonus is called what it is: an extra rune roll (any rune up to Zod), not "high runes".

2026-10-16

1.1.24: Maps 2.0 - map orbs

Three new map orbs let you work your maps in the Horadric Cube - each does exactly what it says:

- Orb of Ascension + a map: the same zone's map of the next tier (Tier 1 and 2 maps).

- Orb of Alteration + a map: the other zone's map of the same tier (Ruined Cathedral <-> Chaos Spire).

- Orb of Duplication + a map: two of that map. The rarest of the three.

Where they drop: inside maps (any monster; champions and uniques much more often), in Hell's Torment and in Hell terror zones (Ascension and Alteration), and from the Three (one orb, often two). A map run gives about 3-4 orbs.

The Maps tab holds them. Each orb has its own stacking slot next to the map grid, with a ghost icon while it's empty. Ctrl+click moves orbs in and out like the other tabs, and Shift+click sends a map from your inventory straight to the Maps tab while the stash is open.

Maps drop more inside maps - about 25% more: regular monsters 1 in 1,900, champions 1 in 190 (next tier), uniques 1 in 13 (next tier).

Maps are always terrorized, and Heralds spawn in the endgame. Maps join Hell's Torment and the Rips in every terror rotation, and Heralds now appear in all three (before, none spawned in Torment at all).

Maps are easier to spot: a loot beam on the ground, and their names are coloured by tier.

2026-10-15

1.1.23: maps in the Loot Filter

Maps have their own Loot Filter group. Open the Loot Filter, edit a rule and go to Items > Misc > Maps - tick the whole group or single maps (Ruined Cathedral / Chaos Spire, Tiers 1-3). Add a Show rule with Maps if you use a Hide All rule, so maps never get hidden with the rest of the misc items. The starter profiles are built into the game, so add the rule yourself - it takes a few seconds.

Mod Information is readable again. The General Information and Heyday Guide tabs no longer squash text under the section titles, and the credits and Soul Summons recipes are spaced out.

2026-10-15

1.1.22: more ways to find maps

Maps now drop in three places outside the maps (all Tier 1):

- Hell's Torment - about twice as often as before: champions and unique packs 1 in 1,365 kills, regular monsters 1 in 10,829. Depth doesn't matter.

- Hell terror zones (new) - champions and unique packs 1 in 1,911, regular monsters 1 in 15,288.

- The rips (new) - champions and unique packs 1 in 3,731, regular monsters 1 in 30,485.

Inside maps nothing changed: unique packs are still your best shot at the next tier.

Hell's Torment level 50 and Icechamber 50 have monsters again. Both levels were spawning nothing but their boss.

Jewels and charms - for real this time. 1.1.18 said the bonus jewel/charm roll was gone from Torment and map monsters, but it kept rolling (a quirk in how the game reads empty drop tables). It's truly gone now: Torment and map monsters drop jewels and charms at the normal rate. The Three keep their rewards.

2026-10-15

1.1.18: jewels and charms back to normal

Torment and map monsters no longer roll a bonus charm or jewel. That extra roll came with a big unique boost - about a third of all uniques found in maps were Rainbow Facets and unique charms. Jewels and charms now drop from Torment and map monsters at the normal Reimagined rate, like any Hell monster.

The Three keep their boosted rewards. Their unique jewel is now a 25% chance per kill (it was 50%, and a sure drop for their terrorized versions); their unique charm and everything else they drop are unchanged.

Launcher 1.2.9: if the league server is briefly down when you close the game, the launcher keeps retrying, and if it's still down, your progress stays safe on your PC and uploads the next time you press Play.

2026-10-15

Deleting a league character

You can now delete a league character for good.

How: delete the character in game the usual way. The next time the launcher runs (or when you close the game), it notices and asks whether to delete it from the league for good. Say yes and it's removed from the vault and won't come back; the name is free again. Say no and it's restored.

Your shared stash is not touched - only that character goes.

If the character played in a session that's still being checked, the launcher asks you to try again in a few minutes. You need launcher 1.2.7 or newer (the launcher updates itself).

2026-10-14

1.1.17: map fixes and a loot pass

Invisible map monsters fixed. Monsters in every map tier were missing their HD models - you could be hit by things you couldn't see. They're all visible now.

Maps drop far less often. A single map run was handing out 50-115 new maps. Now it's about 2 a run: regular monsters drop a same-tier map 1 in 2,401, champions a next-tier map 1 in 241, unique monsters 1 in 16. Hell's Torment's map bonus is 1 in 91.

Loot walked back about 30%, everywhere - including Torment, the rips and the maps. Unique and set items are about 29% rarer and runes about 30% rarer. Everything else drops as before. Magic find works the same as always.

Maps open in Harrogath. Cube a map in the Act 5 town, any difficulty - anywhere else the cube says "I can't use this yet".

Launcher 1.2.8 no longer lists a brief server hiccup during play as a refused upload (it was always retried).

2026-10-13

New on the website: Live and Ladder

The Heyday site has two new tabs.

Ladder - every league character ranked by experience, with a filter for each class and softcore/hardcore. It only counts progress the league has checked: each character stands as it was after its last clean session, and if a session gets rolled back, the ladder moves back with it. A green dot means that player is online right now.

Live - who's playing a league session right now: their character, level, the area they're in, session time, kills, experience per hour and how many uniques and sets have dropped. Live numbers are marked "not judged yet" until the session is checked.

See anyone's gear - click a character on the Ladder (or Gear on a Live card) to open their character sheet: attributes, life and mana, and every equipped item with its full stats, laid out like the in-game equipment screen.

2026-10-13

Heyday 1.1.11: Map stash tab fixed

The Maps tab in the stash behaves now: it always shows the map grid on its own background (it used to show the gems, materials or runes slots of the last tab behind it), the Runes tab can be clicked from it again, clicking the tab you came from takes you straight back, and the map page closes with the stash instead of leaving an outline on screen when you walk away.

2026-10-12

Heyday 1.1.8: skill trees fixed

Some of the new skills that come from items and followers had slipped into the class skill trees and were covering real skills: Telekinesis, Ice Blast, Lightning Fury and Zeal are back where they belong (a Sorceress's "second Teleport" was really Discharge). Those item and follower skills now stay with their items and followers. Their tooltips are complete too - no more "Missing string". If you put points into one of them, use Akara's free skill reset (once per difficulty, after the Den of Evil). The character select screen also shows the right version now.

2026-10-11

Heyday 1.1.5: a fair league

The league now checks every session after you close the game, and rolls back sessions that broke the rules - for everyone in that game. Items have to come from the game itself (drops, vendors, gambling, the cube, quests), gold has to add up (gambling and shopping cost what they cost), and magic find has to match your gear. Finds are announced in #finds only once a session checks out. Playing fair changes nothing for you. Also: if the game or your PC crashes, the launcher now sends that session's record the next time you play, so nothing is lost.

2026-10-11

Heyday 1.1.4: league characters register right away

League fix: a new league character now joins the vault within seconds of being created, while the game is still running, instead of only when you close the game. From then on it uploads every minute as usual. If a new character was turned away before, make a fresh one with the updated launcher (the launcher updates itself). No game data changed, so this update is a small download.

2026-10-11

Heyday 1.1.3: one-click D2RLoader

The launcher now installs D2RLoader for you - the mod loader Heyday runs on, which also adds the Multiplayer menu. It downloads the exact version Heyday is tested with from d2rloader.net, checks it, and switches the Multiplayer button on, so everyone you play with is on a matching setup. Playing together: pick an offline character and press Multiplayer (Public, Unlisted or LAN).

Heyday 1.1.2: loot that climbs

Hell's Torment and the Maps now pay more the deeper you go: every few Torment levels (and every map tier) adds better odds for high runes, endgame uniques and unique charms and jewels. Charms and jewels drop less often but are far more likely to be unique. Champions and uniques roll the extras much more often.
