**Heyday** is a free Diablo II: Resurrected mod: a deep endgame with the 50-level Hell's Torment, the rips, Soul Summons
followers, hundreds of new uniques, sets and runewords, and every class brought up to the same power.

## Download

**[Download HeydayLauncher.exe](https://github.com/mattrav05/heyday-releases/releases/latest/download/HeydayLauncher.exe)**

1. You need Diablo II: Resurrected (Steam or Battle.net) installed.
2. Run `HeydayLauncher.exe`. It finds your game, installs Heyday, keeps it updated and shows the patch notes.
   Windows SmartScreen may warn about a new app: click **More info > Run anyway**.
3. Press **Play**. Your normal D2R characters are not touched; Heyday keeps its own saves.

All releases and patch notes: [Releases](https://github.com/mattrav05/heyday-releases/releases)
